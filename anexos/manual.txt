ativar apache e mysql no xampp

inicia o servidor conectando o sistema ao esp32 utilizando:

php -S 0.0.0.0:8000 -t public public/index.php

and

powershell -ExecutionPolicy Bypass -File scripts\iniciar_teste.ps1 -Porta 8000

caso o php não esteja no path

C:\xampp\php\php.exe -S 0.0.0.0:8000 -t public public/index.php

acessar o servidor no navegador

http://localhost:8000/

acessar o phpmyadmin (banco de dados) e importar o sql

http://localhost/phpmyadmin/

ou 

http://localhost:8080/phpmyadmin/
